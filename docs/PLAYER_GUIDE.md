## 核心循环

```
抽卡获得卡牌 → 提升战力 → 挑战关卡 → 获得金币/券 → 抽卡
     ↑                                              ↓
     └────────── 放置收益（点击/自动/离线）─────────┘
```

## 抽卡系统

### 消耗

| 方式 | 消耗 |
|------|------|
| 单抽 | 1 张抽卡券 |
| 十连 | 10 张抽卡券 |

### 稀有度概率

| 稀有度 | 单抽 | 十连（前9张） | 十连第10张保底 |
|--------|------|--------------|---------------|
| N（普通） | 60% | 39% | — |
| R（稀有） | 25% | 35% | — |
| SR（史诗） | 10% | 18% | 85% |
| SSR（传说） | 5% | 8% | 15% |

### 卡牌升级

- 条件：拥有 **2 张相同卡牌**
- 消耗：1 张（剩余 1 张自动升到下一级）
- 效果：每升 1 级，该卡属性提升 **10%**

## 战斗系统

回合制战斗，最多 100 回合。

### 流程

1. **先攻判定** — 速度高的一方先出手
2. **交替行动** — 双方每回合交换先手权
3. **伤害计算** — `max(1, 攻击力 - 对方防御力 × 0.5)`
4. **暴击** — 暴击率触发时伤害 × (1 + 暴击伤害%)
5. **闪避** — 被攻击时按闪避率概率完全回避伤害

### BOSS 关卡

每世界第 6 关为 BOSS，属性更高：
- 攻击力系数 0.6（普通 0.7）
- 防御力系数 0.4（普通 0.3）
- HP 系数 3.0（普通 2.0）
- 额外 5% 暴击率

## 放置收益

| 类型 | 说明 |
|------|------|
| 点击收益 | 每次点击获得金币，可升级提升 |
| 自动收益 | 每秒自动获得金币，可升级提升 |
| 离线收益 | 离线时间 × 自动收益，**上限 8 小时** |

## 商店

- 自动刷新间隔：**20 分钟**
- 每次刷新随机提供 **3~5 种 N 卡**
- 每种卡牌库存 **1~3 张**
- 抽卡券售价：**500 金币**

## 成就系统

共 **68 个成就**，分为 4 类：

### 数值成就（32个）

累计金币、抽卡次数、竞技胜利、关卡进度四种类别，每类 7~9 个阶梯。

### 系统成就（19个）

- **卡牌收集**（7个）：从"第一张卡"到"全图鉴"
- **卡牌升级**（5个）：从"首次升级"到"传说卡牌（50级）"
- **稀有度收集**（3个）：抽到 R / SR / SSR
- **套装羁绊**（4个）：从"激活第一个"到"激活所有"

### 组合成就（8个）

同时拥有特定卡牌组合或激活特定套装。

### 隐藏成就（9个）

| 名称 | 条件 | 加成 |
|------|------|------|
| 十连保底 | 连续10次抽卡没有 R 以上 | +1% |
| 欧皇附体 | 单抽抽到 SSR | +2% |
| 非酋之王 | 连续100次没有 SSR | +3% |
| 守财奴 | 持有 10万+ 金币但从未抽卡 | +1% |
| 赌徒 | 金币为 0 时抽卡 | +1% |
| 连败者 | 连续失败 10 场 | +1% |
| 绝地反击 | 战力低于敌人 10% 时获胜 | +2% |
| 点击狂魔 | 1 分钟内点击 30+ 次 | +1% |
| 午夜玩家 | 在 0:00-1:00 之间登录 | +1% |

> 所有成就解锁后提供 **powerBonus**（战力加成百分比），累加后提升攻击力、防御力、生命值。
